## What is a graphical user interface (GUI)? 
* A graphical user interface lets you interact with a computer using windows, icons, menus, and buttons.
## What is a desktop environment?
* A desktop environment provides the graphical interface and tools for using a computer.
## What is the command line interface (CLI)?
* A command line interface lets you interact with a computer by typing commands.
## How do I access the command line interface (CLI)?
* You can access the CLI by opening a terminal emulator or using a virtual console.
## What is a virtual console?
* A virtual console is a text-based screen where you can log in and use Linux commands.
## What is a terminal emulator?
* A terminal emulator is a program that lets you use the CLI through a graphical window.
## What is bash?
* Bash is a command-line shell that interprets and executes commands.
## What is the shell prompt?
* The shell prompt is the symbol or text that shows the shell is ready for you to enter a command.

## clear
* Definition:clears the terminal screen
* Usage:`clear`
* Example: to clear screen `clear`
## echo
* Definition:Displays text on the screen
* Usage:`echo` + option string to display
* Example:how to display a line of text
    `echo` "hello"
## date
* Definition:`date` displays the current date and time
* Usage:to find the date
* Example:you want to know the date of today run the `date` command
## free
* Definition:`free` displays information about the computers memory(RAM)usage
* Usage: to know your computer memory
* Example: you want to know the ram if your run free -h it will make it readable 
## uname
* Definition:`uname` displays information about the operating system and kernel
* Usage:used to find system and kernel information
* Example:like `uname -a` displays detailed information about the system
## history
* Definition:`history` displays previously entered commands
* Usage:to find the history of what you typed in your terminal
* Example: trying to find what command you used after you cleared your terminal
## man
* Definition:displays the manuel page for a command
* Usage:to find commands in the manuel 
* Example: man ls it opens a manuel for ls commands
## tldr
* Definition:provides examples and explanations for commands
* Usage:used to quickly learn how to use a command.
* Example:like `tldr ls` it shows you how to use the ls command
## cheat
* Definition:Provides a quick cheat sheet for a command.
* Usage:Used to quickly find common options and examples for commands.
* Example:`cheat ls` displays a cheat sheet containing useful examples
## hostname
* Definition:Displays the name of the computer.
* Usage:used to find the computer's hostname.
* Example:if you want to know your computers name just use `hostname`
## df
* Definition:Displays disk space usage.
* Usage:Used to check how much disk space is used and available.
* Example:if you want to know the disk space you could use `df -h`
## du
* Definition:displays the disk space used by files and directories.
* Usage:used to find how much storage a file or directory is using.
* Example:`du -sh` if you want to know the amount of disk space used by the Documents directory
## figlet
* Definition:displays text using large ASCII-art characters.
* Usage:used to create large decorative text in the terminal.
* Example:If you want a word to look nice you could use `figlet`
